# Schema Reference

All identifiers are PostgreSQL UUIDs generated by `gen_random_uuid()` unless
stated otherwise. Timestamps are `TIMESTAMPTZ` stored in UTC. Tables are grouped
by migration version.

## V1 — Identity and media

### `users`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `email` | VARCHAR(320) | no | unique case-insensitively |
| `password_hash` | VARCHAR(100) | yes | BCrypt; null for Google-only accounts |
| `google_subject` | VARCHAR(255) | yes | unique when present |
| `display_name` | VARCHAR(80) | no | |
| `avatar_url` | VARCHAR(500) | yes | remote URL or `/api/v1/media/{id}` |
| `city` | VARCHAR(80) | yes | |
| `locality` | VARCHAR(120) | yes | |
| `created_at` / `updated_at` | TIMESTAMPTZ | no | `updated_at` maintained by trigger |

Indexes: `uq_users_email_lower (lower(email))`, partial
`uq_users_google_subject`.

### `refresh_tokens`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `user_id` | UUID | no | FK → `users`, cascade |
| `token_hash` | VARCHAR(64) | no | SHA-256 hex, unique |
| `expires_at` | TIMESTAMPTZ | no | |
| `revoked_at` | TIMESTAMPTZ | yes | set on rotation/logout |
| `user_agent` | VARCHAR(255) | yes | reserved |
| `created_at` | TIMESTAMPTZ | no | |

Index: `idx_refresh_tokens_user_active (user_id, expires_at) WHERE revoked_at IS NULL`.

### `media_assets`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `owner_id` | UUID | no | FK → `users`, cascade |
| `storage_key` | VARCHAR(255) | no | unique file name on disk |
| `original_name` | VARCHAR(255) | no | |
| `content_type` | VARCHAR(80) | no | `image/jpeg`, `image/png`, `image/webp` |
| `size_bytes` | BIGINT | no | `> 0` |
| `purpose` | VARCHAR(20) | no | `LISTING` or `AVATAR` |
| `created_at` | TIMESTAMPTZ | no | |

Index: `idx_media_assets_owner (owner_id, created_at DESC)`.

## V2 — Catalogue and listings

### `books`

Canonical, shared catalogue records. One row per edition, not per physical copy.

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `title` | VARCHAR(255) | no | |
| `author` | VARCHAR(255) | no | |
| `publisher` | VARCHAR(255) | yes | |
| `isbn` | VARCHAR(20) | yes | validated pattern, unique when present |
| `class_level` | SMALLINT | no | 1–12 |
| `education_board` | VARCHAR(20) | no | `CBSE`, `ICSE`, `IB`, `STATE_BOARD`, `OTHER` |
| `subject` | VARCHAR(120) | no | |
| `edition` | VARCHAR(80) | yes | |
| `language` | VARCHAR(60) | no | default `English` |
| `dedupe_key` | TEXT (generated) | no | unique normalized identity |
| `search_vector` | TSVECTOR (generated) | no | full-text index source |
| `created_at` / `updated_at` | TIMESTAMPTZ | no | |

Indexes: `uq_books_dedupe_key`, partial `uq_books_isbn`,
`idx_books_search_vector` (GIN), `idx_books_filters`.

### `collections`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `owner_id` | UUID | no | FK → `users`, cascade |
| `title` | VARCHAR(120) | no | |
| `description` | VARCHAR(1000) | yes | |
| `city` | VARCHAR(80) | no | |
| `locality` | VARCHAR(120) | yes | |
| `created_at` / `updated_at` | TIMESTAMPTZ | no | |

Constraint `uq_collections_id_owner (id, owner_id)` supports the composite FK
from listings. Index: `idx_collections_owner`.

### `listings`

A physical copy offered by a user.

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `owner_id` | UUID | no | FK → `users`, cascade |
| `book_id` | UUID | no | FK → `books`, restrict |
| `collection_id` | UUID | yes | composite FK with `owner_id` |
| `condition` | VARCHAR(20) | no | `NEW`, `LIKE_NEW`, `GOOD`, `FAIR`, `POOR` |
| `price_type` | VARCHAR(20) | no | `FREE`, `FIXED_PRICE`, `NEGOTIABLE` |
| `price` | NUMERIC(10,2) | yes | required for fixed, optional for negotiable |
| `city` | VARCHAR(80) | no | |
| `locality` | VARCHAR(120) | yes | |
| `notes` | VARCHAR(2000) | yes | |
| `status` | VARCHAR(20) | no | default `AVAILABLE` |
| `version` | BIGINT | no | optimistic locking, default 0 |
| `created_at` / `updated_at` | TIMESTAMPTZ | no | |

Indexes: `idx_listings_owner_status`, `idx_listings_book`,
`idx_listings_status_created`, `idx_listings_status_city_locality_created`,
`idx_listings_status_price_condition_created`.

### `listing_images`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `listing_id` | UUID | no | FK → `listings`, cascade |
| `media_id` | UUID | no | FK → `media_assets`, restrict |
| `position` | SMALLINT | no | 0–4, unique per listing |

Unique constraints: `(listing_id, media_id)`, `(listing_id, position)`.

## V3 — Communication

### `conversations`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `type` | VARCHAR(20) | no | currently only `DIRECT` |
| `listing_id` | UUID | yes | FK → `listings`, set null on delete |
| `direct_key` | VARCHAR(120) | yes* | `listing:lowUser:highUser` |
| `last_message_at` | TIMESTAMPTZ | no | updated by trigger |
| `created_at` | TIMESTAMPTZ | no | |

\* Required while the conversation is `DIRECT` by check constraint.
Indexes: unique `uq_conversations_direct_key`,
`idx_conversations_last_message`, `idx_conversations_listing`.

### `messages`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | BIGINT identity | no | PK, monotonic |
| `conversation_id` | UUID | no | FK → `conversations`, cascade |
| `sender_id` | UUID | no | FK → `users`, cascade |
| `body` | VARCHAR(4000) | no | non-blank |
| `created_at` | TIMESTAMPTZ | no | |

Index: `idx_messages_conversation_id_desc (conversation_id, id DESC)`.
Trigger: `trg_messages_touch_conversation` updates `conversations.last_message_at`.

### `conversation_participants`

| Column | Type | Null | Notes |
| --- | --- | --- | --- |
| `id` | UUID | no | PK |
| `conversation_id` | UUID | no | FK, cascade |
| `user_id` | UUID | no | FK, cascade |
| `role` | VARCHAR(20) | no | `OWNER` or `INTERESTED` |
| `joined_at` | TIMESTAMPTZ | no | |
| `last_read_message_id` | BIGINT | yes | FK → `messages`, set null |

Unique `(conversation_id, user_id)`; index
`idx_conversation_participants_user (user_id, conversation_id)`.

## Helper objects

| Object | Purpose |
| --- | --- |
| `set_updated_at()` | Trigger function for `users`, `books`, `collections`, `listings` |
| `touch_conversation_last_message()` | Keeps conversation ordering correct after inserts |
